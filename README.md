Fingerprint-Based Telegram Alert System

Project Overview

This project provides fingerprint-based access control using an ESP8266 NodeMCU and R307 fingerprint sensor.

Working Principle

- Registered fingerprint: Access is granted.
- Unregistered fingerprint: A Telegram alert is sent.
- Wi-Fi is used to send notifications through a Telegram bot.

Hardware Components

- ESP8266 NodeMCU
- R307 Fingerprint Sensor
- Wi-Fi connection
- Telegram Bot

Technologies Used

- Embedded C / Arduino IDE
- ESP8266
- Fingerprint Authentication
- Telegram Bot API
